# Data Analyst Portfolio

A modern, responsive portfolio website built with React and Vite, showcasing data analysis projects and professional experience.

## 🚀 Tech Stack

- **Core Technologies**:
  - [HTML5](https://developer.mozilla.org/en-US/docs/Web/HTML)
  - [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)
  - [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
  - [TypeScript](https://www.typescriptlang.org/)

- **Frontend Framework & Tools**:
  - [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
  - [Tailwind CSS](https://tailwindcss.com/) for styling
  - [Lucide React](https://lucide.dev/) for icons
  - [Framer Motion](https://www.framer.com/motion/) for animations
  - [React Router](https://reactrouter.com/) for navigation

- **Development Tools**:
  - [Node.js](https://nodejs.org/) & [npm](https://www.npmjs.com/)
  - [ESLint](https://eslint.org/) for code linting
  - [PostCSS](https://postcss.org/) for CSS processing
  - [Git](https://git-scm.com/) for version control

- **Features**:
  - Dark/Light mode support
  - Responsive design
  - GitHub Pages deployment

## ✨ Features

- **Modern UI**: Clean and responsive design with dark/light mode support
- **Sections**:
  - Hero section with animated introduction
  - About section with professional background
  - Projects showcase
  - Skills section
  - Professional experience timeline
  - Contact section with social media links
- **Responsive Design**: Works seamlessly on all devices
- **Smooth Scrolling**: Enhanced user experience with smooth navigation
- **Interactive Elements**: Hover effects and animations

## 🛠️ Installation

1. Clone the repository:
```bash
git clone https://github.com/kryelgulwar/Portfolio.git
cd Portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 📁 Project Structure

```
src/
├── components/
│   ├── layout/         # Layout components (Navbar, Footer)
│   ├── sections/       # Page sections (Hero, About, Projects, etc.)
│   ├── theme/          # Theme-related components
│   └── ui/             # Reusable UI components
├── App.tsx             # Main application component
└── main.tsx            # Application entry point
```

## 🎨 Customization

- Update personal information in the respective section components
- Modify the theme colors in the `tailwind.config.js`
- Add or remove sections as needed
- Update social media links in the Contact component
